# EASY EDITING

## Edit this file most often
`site-data.js`

It contains your:
- profile text
- official links
- research projects
- publications
- courses
- highlights

- `about.html`
- `contact.html`

## GitHub workflow
1. Open the repository.
2. Click `site-data.js`.
3. Click the pencil icon.
4. Edit text.
5. Click Commit changes.
6. Netlify automatically republishes the website.

For major layout changes, update the relevant HTML file or ask ChatGPT to revise the site package.
