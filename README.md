# Jaeyeon Chung Multi-Page Website

Upload every file and the complete `assets` folder to the root of the GitHub repository. Netlify will redeploy automatically after the commit.

The research cards link to `research-study.html`, and their page content is supplied by `research-study.js`. Both files and all research images in `assets` are required.


## AI / answer-engine discoverability (v18)
- `expertise.html` uses clearer consumer-behavior, perception, digital-platform, AI/recommendation, survey, experiment, and marketplace-data language.
- `site.js` adds a discreet internal footer link to the Expertise page across the site.
- Person structured data uses consistent `knowsAbout` terms across key pages.
- `llms.txt` provides a concise machine-readable identity/expertise map for AI systems that choose to use it.
- `robots.txt` explicitly permits common search/answer-engine crawlers in addition to the universal allow rule.
- `sitemap.xml` now includes `lastmod` dates.
